# Overview - WavePro for AWS

WavePro empowers you to monitor your daily and monthly AWS cost data in near real-time. As an advanced version of the traditional Wave, it offers more granular filtering and reporting capabilities, all designed with a strong focus on user-friendliness.

**Important Notes**

1. Data transfer for services such as EC2 (Amazon Elastic Compute Cloud) and RDS (Amazon Relational Database Service) will appear as a separate line item under "AWS Data Transfer".
2. EBS (Amazon Elastic Block Store) charges are included and displayed within your EC2 costs.
